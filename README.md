# ⬡ Cirqus Heresy — Governance

*Capital strengthens the Order. It does not buy command of it.*

Everything a member — or a sceptic — needs to verify how the Order decides, who holds which seat, and where the money goes.

| Folder | What's inside |
|---|---|
| [`CHARTER.md`](CHARTER.md) | Proposed governance framework: chambers, signs, Hexastorm. **Draft, not adopted.** |
| [`decisions/`](decisions/) | Log of every decision that affects the Order, one file each |
| [`treasury/`](treasury/) | Treasury addresses and how funds are controlled |
| [`reports/`](reports/) | Periodic reports: what was built, spent, learned |

## Principles

1. **If it isn't written here, it wasn't decided.** Decisions made in Discord or calls get logged here within 7 days.
2. **Public by default.** Personal data of members is the only exception.
3. **Every change is a pull request.** History of the charter is the git history of this file — nobody can quietly rewrite it.

## How to propose a change

Open an issue using the **Proposal** template, mark whether it affects one chamber or both, and link it to a pull request that edits the charter or adds a decision record.
